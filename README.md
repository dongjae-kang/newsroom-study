# The Newsroom Study

[학습 사이트 열기](https://dongjae-kang.github.io/newsroom-study/)

The Newsroom으로 영어 표현과 미국 정치·미디어 맥락을 함께 공부하는 개인 학습 사이트입니다. 설명은 한국어, 표현과 연습 예문은 영어로 구성했습니다.

## 연속 읽기가 기본 화면입니다

에피소드 전체의 흐름을 먼저 따라가고 필요한 대목의 해설을 펼칩니다. 기존의 짧은 구문 연습은 보조 학습으로 유지합니다. 전체 스크립트와 번역이 기본 제공되는 상태는 아닙니다.

- 사용자가 제공한 영어 SRT·VTT·TXT 또는 영한 병렬 JSON을 읽습니다.
- 한국어 SRT·VTT·TXT를 추가하면 시간 겹침 또는 줄 순서로 연결합니다. 시간 보정 값을 지정할 수 있으며, 연결되지 않은 한글도 별도로 보존합니다.
- 전체 스크롤, 원문·번역 검색, 한글 가리기, 읽던 위치와 개인 메모 저장을 지원합니다.
- 파일 내용은 브라우저에서만 처리하고 IndexedDB에 보관합니다. 읽기 자료 내보내기 JSON에는 원문·번역·메모·읽던 위치가 포함됩니다.
- 영어만 불러온 경우 자동 번역하지 않습니다. 없는 번역과 아직 작성하지 않은 해설은 그대로 표시합니다.
- 다른 기기로 옮기려면 개인 읽기 JSON을 내보내고 새 기기에서 영어 자료 입력으로 다시 불러옵니다. 복습 진도 백업과는 별도의 파일입니다.

## 현재 준비된 자료

- 전 3시즌 25편의 에피소드 목록과 영어 전사본 출처
- S1E1 배경 브리핑 7개와 도입부 학습 구문 2개
- 직역·의역, 문장 구조, 격과 뉘앙스, 역사적 맥락, 직접 만든 예문
- 준비된 범위를 확인하는 퀴즈 5문항
- 브라우저에 저장되는 자기 예문과 복습 기록
- 첫 학습일 기준 D+1·3·7·14·30 복습 안내, JSON 백업과 가져오기

전체 25편의 학습 노트가 완성된 상태는 아닙니다. 나머지 에피소드는 출처부터 확인할 수 있으며, S1E1부터 장면 단위로 노트를 채웁니다. 준비 상태와 실제 학습 완료를 구분합니다.

## 자료와 출처

콘텐츠 정본은 `data/course.json`입니다. `notes/`의 Markdown은 이 파일에서 생성합니다. 직접 만든 예문은 방송 대사와 구분합니다. 외부 전사본은 비공식 출처이며, 페이지·본문 존재 확인과 문구·화자·시간의 검증은 서로 다릅니다. 인용 시간은 판본을 명시하고 HBO 시간으로 추정하지 않습니다. 대본·자막 전문 파일은 이 저장소에 포함하지 않습니다.

HBO와 관련 없는 독립적인 학습 프로젝트입니다. 작품과 등장인물에 대한 권리는 각 권리자에게 있습니다.

## 개발과 업데이트

별도 빌드나 패키지 설치 없이 HTML, CSS, JavaScript로 실행합니다.

```sh
python3 scripts/generate-notes.py
python3 scripts/check.py
node --check assets/app.js
node --test scripts/reader.test.mjs
python3 -m http.server 8767 --bind 127.0.0.1
```

GitHub Pages는 `main` 브랜치의 루트에서 배포합니다. `data/course.json`의 에피소드 정보를 갱신하고 노트를 재생성한 뒤 검사하고 push합니다. 에피소드별 항목 수와 준비 상태도 함께 갱신합니다. 단위 ID는 학습 기록의 연결 기준이므로 변경하지 않습니다.

진도는 사이트 방문자의 `localStorage`에 보관됩니다. 서버 동기화나 자동 알림은 없습니다. 기기를 옮기거나 브라우저 데이터를 지우기 전에 복습 화면에서 진도를 내보내세요. 백업을 불러오면 현재 브라우저의 진도가 교체됩니다. GitHub에는 학습자의 답변을 올리지 않습니다.

## 영한 병렬 JSON 형식

직접 제공한 원문을 번역·해설한 자료는 다음 형식으로 읽을 수 있습니다. 아래 문장은 형식을 설명하기 위해 새로 만든 예문입니다.

```json
{
  "app": "newsroom-reader",
  "version": 1,
  "episode": "S01E01",
  "alignment": "provided_pairs",
  "cues": [
    {
      "start": null,
      "end": null,
      "english": "What would count as evidence?",
      "korean": "무엇을 근거로 인정할 수 있을까요?",
      "literal": "무엇이 증거에 해당할까요?",
      "note": "판단 기준을 먼저 정하는 질문. would는 가정하거나 제안하는 느낌을 준다."
    }
  ]
}
```

시간이 있으면 start와 end에 초 단위 숫자를 넣습니다. 한글 파일을 별도로 연결한 결과는 의미를 이해한 번역 정렬이 아니므로 사용 중 확인이 필요합니다. 텍스트 정렬·파싱 관련 기준: [WebVTT 형식](https://developer.mozilla.org/en-US/docs/Web/API/WebVTT_API/Web_Video_Text_Tracks_Format), [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API).

## 검증 범위

SRT·VTT·일반 텍스트 파싱, 시간·줄 대응, 번역 누락 표시, JSON 형식 검사에 대한 자동 검사를 실행합니다. 브라우저에서는 직접 만든 예문을 붙여넣어 병렬 읽기·검색·한글 가리기·메모와 읽던 위치의 재접속 보존을 확인했습니다. 파일 선택 대화상자와 실제 전편 자막을 사용한 검증은 남아 있습니다.
